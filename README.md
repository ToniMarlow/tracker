# Трекер задач: что осталось сделать

База данных в Supabase уже создана, адрес и ключ проекта уже вписаны в `www/config.js`. Остались три простых блока.

## 1. Supabase: одна настройка (1 минута)

Откройте свой проект на supabase.com, слева **Authentication**, затем настройки входа по почте (**Sign In / Providers**, пункт **Email**). Выключите переключатель **Confirm email** и нажмите **Save**. Иначе при регистрации нужно будет подтверждать почту по письму.

## 2. GitHub

1. На github.com нажмите **New repository**. Имя: `tracker`. Выберите **Public** (нужно, чтобы бесплатно работала версия для компьютера). Нажмите **Create repository**.
2. Распакуйте архив. На странице нового репозитория нажмите ссылку **uploading an existing file** и перетащите всё содержимое распакованной папки: файлы `package.json`, `capacitor.config.json`, `supabase.sql`, `README.md` и папки `www` и `.github`. Внизу нажмите **Commit changes**.
   - Если папка `.github` не загрузилась (она скрытая): **Add file**, затем **Create new file**. В поле имени введите `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` из архива и нажмите **Commit changes**.
3. Откройте **Settings**, затем **Pages**. В поле **Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions**. Сборка запустится сама и займёт 10–15 минут. Дождитесь зелёной галочки. Если сборка запустилась до шага 3 и страница для компьютера не создалась, откройте последнюю сборку и нажмите **Re-run all jobs**.

## 3. Установка

1. На главной странице репозитория справа найдите **Releases**, откройте последний релиз и скачайте файл `app-debug.apk` на телефон.
2. Откройте файл. Телефон попросит разрешить установку из неизвестных источников: разрешите и установите.
3. Запустите «Трекер задач», нажмите **Создать аккаунт** (почта и пароль не короче 6 символов) и разрешите уведомления.
4. На компьютере откройте `https://ВАШ_ЛОГИН_GITHUB.github.io/tracker/` и войдите той же почтой. Задачи будут общими.

## Важно знать

- **Обновление.** Каждая новая сборка подписывается новым ключом, поэтому новую версию нельзя поставить поверх старой. Сначала удалите старое приложение, затем установите новое и войдите снова. Задачи хранятся в Supabase и не пропадут.
- **Уведомления.** Они планируются на телефоне на 7 дней вперёд: когда время задачи вышло и в 21:00 с итогами дня. Планирование обновляется, когда вы открываете приложение. На некоторых телефонах нужно разрешить работу в фоне: Настройки, Приложения, Трекер задач, Батарея, «Без ограничений» (на Xiaomi также включите «Автозапуск»).
- **ИИ.** В этой версии ИИ нет, его можно добавить позже.
